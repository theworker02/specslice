Read a markdown file and print ATX headings plus fenced code-block identifiers.

Package version: **1.00** (`1.0.0`).

## Install

```bash
git clone https://github.com/theworker02/specslice.git
cd specslice
npm install -g .
```

## Usage

```bash
specslice README.md
```
