# specslice

<img src="docs/logo.svg" alt="specslice mark" width="72" height="72">

Read a markdown file and print ATX headings plus fenced code-block identifiers.

## Install

```bash
git clone https://github.com/theworker02/specslice.git
cd specslice
npm install -g .
```

## Usage

```bash
specslice README.md
```
